A CLEARER KIND OF LOCAL COMMERCE

Useful information.
No pretend certainty.

NearCart is built around a simple problem: the address is not enough. Before travelling, people need to know whether a product is listed, how recent the data is and what alternatives exist.

01

Search the catalogue

Listings are matched by product name, category, keywords and store name. Results include price, stock count, location, freshness and an estimated confidence indicator.

02

Freshness is part of the answer

Fresh: the inventory row was updated within the past hour. Aging: within the past 24 hours. Stale: older than 24 hours. A timestamp cannot guarantee shelf reality, but it gives the shopper useful context.

03

Rank for practical value

The matching score considers recorded stock, update freshness, confidence and price, plus distance when the shopper shares location. Search distance is straight-line approximation. A production ranking should prefer road ETA, opening status and shopper preference.

04

Plan fewer stops

The trip planner uses a greedy coverage heuristic to group saved items into fewer shops. It is intentionally explained rather than marketed as an optimal algorithm. A fuller version could optimise travel time and item quantities together.

05

Inventory, with context

The Pune catalogue is preloaded with illustrative store listings so the search, maps and planning tools are ready to explore. Changes made in Retailer Studio persist locally. Verified, live stock requires a participating retailer to connect a POS feed or inventory API.

06

Location is optional

The app can be browsed without location permission. If granted, the browser supplies coordinates to calculate approximate straight-line distance. Coordinates are not saved to the inventory database.

OPEN TOOLKIT

Free foundations. Sensible limits.

Flask + SQLite

Local backend and persistent project inventory.

Leaflet

Open-source interactive map library.

OpenStreetMap

Community map data and standard tile service with attribution and usage rules.

Browser APIs

Optional geolocation, localStorage and page-active notifications.

OSRM / map links

Road-route previews can use the public OSRM endpoint during development; directions links open an external maps app.

Public map and routing services are not guaranteed infrastructure. For production, follow service policies, cache responsibly, use an appropriate provider, and never expose secret API keys in frontend code.
